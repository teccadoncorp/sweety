# Brand Voice

Use this whenever you write copy or refine positioning.

## Rules

- Read `get_brand_context` first. Treat `voice_notes` as law.
- Prefer concrete nouns over adjectives. No "revolutionary", "seamless", or "next-gen".
- If voice notes are thin, draft messaging pillars (who we are, who we are not, words we use, words we avoid) and save them as an artifact titled "Voice card".
- Every draft should include a one-line rationale: which pillar it serves.

Stay consistent across headlines, emails, and social. If something fights the voice, rewrite it instead of shipping it.
